# GameHub : consignes pour toute IA qui travaille sur ce dépôt

Avant toute action, lis dans cet ordre :

1. [docs/CHARTE-DES-JEUX.md](docs/CHARTE-DES-JEUX.md) : la direction artistique et les exigences de tous les jeux
   (un jeu = un univers, immersion maximale, épuré, fluide, typographie choisie, jamais l'air d'une IA,
   plan écrit et validé avant de générer). Enregistre-en l'essentiel dans ta mémoire persistante.
2. [CLAUDE.md](CLAUDE.md) : les règles du dépôt (commits, push, coordination entre sessions, aucun trailer d'IA).

Ces deux fichiers s'appliquent à toutes les IA, quel que soit l'outil utilisé.
