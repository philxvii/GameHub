## 🛠️ Sous le capot

Un site léger, en HTML, CSS et JavaScript natifs, sans framework, qui se joue dans n'importe quel
navigateur, sur téléphone comme sur ordinateur. Les parties se synchronisent en temps réel entre
les joueurs.
